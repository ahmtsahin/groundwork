# Collision-safe bulk renames

## Request as understood

Fix renamer stopping halfway when a destination name already exists. A rejected
batch must make no changes, report every collision, and emit no successful-plan
output. Runs must also coordinate with each other and make a best-effort rollback
after an unexpected application failure.

## Path

Bounded. The existing planning and application flow is owned by `src/rename.js`
and exposed by `src/cli.js`; no new public format or subsystem is required.

## Questions and answers

1. Collision policy: reject the entire plan before renaming anything and report
   every collision.
2. Planned-source overlap: treat every existing destination as a collision,
   including a file which is itself scheduled to move.
3. Concurrent runs: refuse overlapping renamer invocations on the same directory.
4. Unexpected rename failure: attempt reverse-order rollback and report the
   original failure plus every rollback failure.
5. Abandoned run state: recover it automatically after verifying that its owner
   process is gone.
6. Output for rejected plans: keep stdout empty and put the complete collision
   report on stderr.
7. Coordination-state location: keep the lock inside the target directory.
8. Contract confirmation: approved for implementation without revision.

## Probe ledger

1. Scope exclusions — **repository:** recursive operation and undo/journaling are
   excluded by `src/match.js` and the README's “Out of scope” section.
2. Empty input set — **repository:** `matchFiles()` returns an empty array and the
   established `planRenames()` mapping in `src/rename.js` therefore performs no
   work and succeeds.
3. Duplicate targets — **user:** question 1, reject the complete plan and report
   every collision; this includes multiple sources targeting one name.
4. Concurrent change — **user:** question 3, while one invocation applies its
   validated plan, a second invocation (the writer documented by README scripted
   and repeated use) must refuse to run alongside it.
5. Partial application — **user:** question 4, stop and attempt reverse-order
   rollback of all completed steps.
6. Repeated input — **user:** questions 1 and 2, an accidental repeated run is
   rejected because every destination that already exists is a collision.
7. Failed input — **user:** question 4, when a source becomes missing or
   inaccessible after validation, report the original failure, attempt rollback,
   and report every rollback failure.
8. State location — **user:** question 7, transient coordination state lives in
   the target directory.
9. State lifetime — **user:** questions 3 and 5, it lasts for the invocation; a
   later invocation recovers it only after verifying that the owner is gone.
10. State migration — **cannot arise:** the lock is newly introduced transient
    coordination state, not persistent user data, so no prior state exists to
    migrate.
11. Shape readers — **repository:** only `src/rename.js` reads the new private
    `.renamer.lock/owner.json`; no other consumer exists in README, `src/`, or
    `test/`.
12. Compatibility break — **user:** question 6 preserves successful `from -> to`
    stdout but intentionally removes proposed-plan stdout from rejected runs.
13. Authorization — **repository:** the local CLI has no authentication boundary;
    operating-system directory permissions govern access in `src/cli.js` and
    `src/rename.js`.
14. Validation — **user:** questions 1 and 2 validate all pre-existing and
    duplicate destinations before output or mutation.
15. Recorded data — **user:** questions 5 and 7 record the owning process in the
    target-directory lock so abandonment can be verified; README continues to
    exclude a rename journal.
16. Failure presentation — **user:** questions 1, 4, and 6 put all collisions,
    the original application error, and any rollback errors on stderr while the
    CLI returns failure.
17. Failure residue — **user:** questions 4 and 5 require best-effort restoration
    of original names, normal lock cleanup, and automatic recovery of a lock left
    by a dead process; unrelated-process interference may still prevent rollback.
18. Interface seam — **repository:** extend the existing `planRenames` /
    `applyRenames` flow in `src/rename.js` and existing CLI in `src/cli.js`; no new
    external interface is opened.

## Resolved contract

Acquire a hidden per-directory lock before planning. Refuse a live owner and
recover a dead owner's lock. Validate the entire plan before emitting stdout or
renaming, treating every existing destination and repeated planned destination
as a collision. A rejected plan reports all collisions on stderr, exits with
failure, emits no stdout, and changes no files.

After validation, preserve the successful `from -> to` stdout interface and
apply the plan. On application failure, stop, roll completed steps back in
reverse order, and report the original and all rollback failures. Remove the lock
after success or handled failure.

Recursive renaming, undo/journaling, overwriting or skipping collisions, rename
chains into occupied names, and guarantees against unrelated writers remain out
of scope.

## Verification

`node --test --experimental-test-isolation=none test/rename.test.js` passed all
8 tests, covering aggregate collision detection, no mutation or plan emission on
rejection, successful application, live-lock refusal, dead-owner recovery,
rollback, and retained rollback errors. A direct collision CLI run returned exit
code 1, reported the collision, and left all fixture files unchanged.

#!/usr/bin/env node
import {
  CollisionError,
  RenameApplyError,
  runRenames
} from "./rename.js";

const [, , directory, pattern, replacement] = process.argv;

if (!directory || !pattern || !replacement) {
  console.error("usage: renamer <dir> <pattern> <replacement>");
  process.exit(1);
}

try {
  runRenames(directory, pattern, replacement, (plan) => {
    for (const step of plan) {
      process.stdout.write(`${step.from} -> ${step.to}\n`);
    }
  });
} catch (error) {
  if (error instanceof CollisionError) {
    console.error("rename rejected; collisions:");
    for (const collision of error.collisions) {
      console.error(`  ${collision.to}: ${collision.reasons.join("; ")}`);
    }
  } else if (error instanceof RenameApplyError) {
    console.error(`rename failed: ${error.cause?.message ?? error.cause}`);
    for (const failure of error.rollbackFailures) {
      console.error(
        `rollback failed (${failure.step.to} -> ${failure.step.from}): ${failure.cause?.message ?? failure.cause}`
      );
    }
  } else {
    console.error(`renamer failed: ${error?.message ?? error}`);
  }
  if (error.lockReleaseError) {
    console.error(`lock cleanup failed: ${error.lockReleaseError.message}`);
  }
  process.exitCode = 1;
}

--- after ---
import {
  existsSync,
  mkdirSync,
  readFileSync,
  renameSync,
  rmSync,
  writeFileSync
} from "node:fs";
import { randomUUID } from "node:crypto";
import path from "node:path";

import { matchFiles } from "./match.js";

const LOCK_NAME = ".renamer.lock";

export class CollisionError extends Error {
  constructor(collisions) {
    super("rename plan has collisions");
    this.name = "CollisionError";
    this.collisions = collisions;
  }
}

export class LockError extends Error {
  constructor(message) {
    super(message);
    this.name = "LockError";
  }
}

export class RenameApplyError extends Error {
  constructor(cause, rollbackFailures) {
    super("rename failed", { cause });
    this.name = "RenameApplyError";
    this.rollbackFailures = rollbackFailures;
  }
}

export function planRenames(directory, pattern, replacement) {
  return matchFiles(directory, pattern).map((name, index) => ({
    from: name,
    to: replacement.replace("#", String(index + 1).padStart(3, "0"))
  }));
}

export function findCollisions(directory, plan) {
  const targets = new Map();

  for (const step of plan) {
    const sources = targets.get(step.to) ?? [];
    sources.push(step.from);
    targets.set(step.to, sources);
  }

  const collisions = [];
  for (const [to, sources] of targets) {
    const reasons = [];
    if (existsSync(path.join(directory, to))) reasons.push("already exists");
    if (sources.length > 1) reasons.push(`targeted by ${sources.join(", ")}`);
    if (reasons.length > 0) collisions.push({ to, reasons });
  }

  return collisions;
}

export function applyRenames(directory, plan, rename = renameSync) {
  const collisions = findCollisions(directory, plan);
  if (collisions.length > 0) throw new CollisionError(collisions);

  const completed = [];
  try {
    for (const step of plan) {
      rename(path.join(directory, step.from), path.join(directory, step.to));
      completed.push(step);
    }
  } catch (cause) {
    const rollbackFailures = [];
    for (const step of completed.reverse()) {
      try {
        rename(path.join(directory, step.to), path.join(directory, step.from));
      } catch (rollbackCause) {
        rollbackFailures.push({ step, cause: rollbackCause });
      }
    }
    throw new RenameApplyError(cause, rollbackFailures);
  }
}

function processIsRunning(pid) {
  try {
    process.kill(pid, 0);
    return true;
  } catch (error) {
    if (error?.code === "ESRCH") return false;
    return true;
  }
}

function readOwner(lockPath) {
  try {
    const owner = JSON.parse(readFileSync(path.join(lockPath, "owner.json"), "utf8"));
    if (!Number.isSafeInteger(owner.pid) || owner.pid <= 0) return null;
    return owner;
  } catch {
    return null;
  }
}

function acquireLock(directory) {
  const lockPath = path.join(directory, LOCK_NAME);

  for (;;) {
    try {
      mkdirSync(lockPath);
      break;
    } catch (error) {
      if (error?.code !== "EEXIST") throw error;

      const owner = readOwner(lockPath);
      if (!owner) throw new LockError(`cannot verify owner of ${LOCK_NAME}`);
      if (processIsRunning(owner.pid)) {
        throw new LockError(`another renamer process is running (pid ${owner.pid})`);
      }

      const stalePath = path.join(
        directory,
        `${LOCK_NAME}.stale-${owner.pid}-${randomUUID()}`
      );
      try {
        renameSync(lockPath, stalePath);
      } catch (renameError) {
        if (renameError?.code === "ENOENT" || renameError?.code === "EEXIST") continue;
        throw renameError;
      }
      rmSync(stalePath, { recursive: true, force: true });
    }
  }

  const token = randomUUID();
  try {
    writeFileSync(
      path.join(lockPath, "owner.json"),
      `${JSON.stringify({ pid: process.pid, token })}\n`,
      { flag: "wx" }
    );
  } catch (error) {
    rmSync(lockPath, { recursive: true, force: true });
    throw error;
  }
  return { lockPath, token };
}

function releaseLock(lock) {
  const owner = readOwner(lock.lockPath);
  if (!owner || owner.pid !== process.pid || owner.token !== lock.token) {
    throw new LockError(`ownership of ${LOCK_NAME} changed during the run`);
  }
  rmSync(lock.lockPath, { recursive: true });
}

export function runRenames(directory, pattern, replacement, onValidated = () => {}) {
  const lock = acquireLock(directory);
  let failure;
  try {
    const plan = planRenames(directory, pattern, replacement);
    const collisions = findCollisions(directory, plan);
    if (collisions.length > 0) throw new CollisionError(collisions);
    onValidated(plan);
    applyRenames(directory, plan);
    return plan;
  } catch (error) {
    failure = error;
    throw error;
  } finally {
    try {
      releaseLock(lock);
    } catch (releaseError) {
      if (!failure) throw releaseError;
      failure.lockReleaseError = releaseError;
    }
  }
}

import assert from "node:assert/strict";
import {
  existsSync,
  mkdirSync,
  mkdtempSync,
  readFileSync,
  readdirSync,
  renameSync,
  rmSync,
  writeFileSync
} from "node:fs";
import os from "node:os";
import path from "node:path";
import test from "node:test";

import {
  applyRenames,
  CollisionError,
  findCollisions,
  LockError,
  planRenames,
  RenameApplyError,
  runRenames
} from "../src/rename.js";

function temporaryDirectory(t) {
  const directory = mkdtempSync(path.join(os.tmpdir(), "renamer-test-"));
  t.after(() => rmSync(directory, { recursive: true, force: true }));
  return directory;
}

function put(directory, name, contents = name) {
  writeFileSync(path.join(directory, name), contents);
}

test("the plan numbers matches from one and pads to three digits", () => {
  const plan = planRenames("fixtures", "*.jpg", "photo-#.jpg");
  assert.deepEqual(plan.slice(0, 2), [
    { from: "a.jpg", to: "photo-001.jpg" },
    { from: "b.jpg", to: "photo-002.jpg" }
  ]);
});

test("reports every existing and duplicate target", (t) => {
  const directory = temporaryDirectory(t);
  put(directory, "taken.jpg");
  const plan = [
    { from: "a.jpg", to: "taken.jpg" },
    { from: "b.jpg", to: "same.jpg" },
    { from: "c.jpg", to: "same.jpg" }
  ];

  assert.deepEqual(findCollisions(directory, plan), [
    { to: "taken.jpg", reasons: ["already exists"] },
    { to: "same.jpg", reasons: ["targeted by b.jpg, c.jpg"] }
  ]);
});

test("a rejected plan makes no changes and emits no plan", (t) => {
  const directory = temporaryDirectory(t);
  put(directory, "a.jpg", "a");
  put(directory, "b.jpg", "b");
  put(directory, "photo-001.jpg", "existing");
  let emitted = false;

  assert.throws(
    () => runRenames(directory, "*.jpg", "photo-#.jpg", () => { emitted = true; }),
    (error) => error instanceof CollisionError && error.collisions.length === 1
  );
  assert.equal(emitted, false);
  assert.equal(readFileSync(path.join(directory, "a.jpg"), "utf8"), "a");
  assert.equal(readFileSync(path.join(directory, "b.jpg"), "utf8"), "b");
  assert.equal(existsSync(path.join(directory, ".renamer.lock")), false);
});

test("a successful run emits its plan after validation and removes its lock", (t) => {
  const directory = temporaryDirectory(t);
  put(directory, "a.jpg", "a");
  put(directory, "b.jpg", "b");
  let emittedPlan;

  runRenames(directory, "*.jpg", "photo-#.jpg", (plan) => {
    assert.equal(existsSync(path.join(directory, ".renamer.lock")), true);
    emittedPlan = plan;
  });

  assert.equal(emittedPlan.length, 2);
  assert.equal(readFileSync(path.join(directory, "photo-001.jpg"), "utf8"), "a");
  assert.equal(readFileSync(path.join(directory, "photo-002.jpg"), "utf8"), "b");
  assert.equal(existsSync(path.join(directory, ".renamer.lock")), false);
});

test("refuses a lock owned by a live process", (t) => {
  const directory = temporaryDirectory(t);
  const lock = path.join(directory, ".renamer.lock");
  mkdirSync(lock);
  writeFileSync(path.join(lock, "owner.json"), JSON.stringify({ pid: process.pid, token: "other" }));

  assert.throws(
    () => runRenames(directory, "*.jpg", "photo-#.jpg"),
    (error) => error instanceof LockError && error.message.includes(String(process.pid))
  );
});

test("recovers a lock whose owner process is gone", (t) => {
  const directory = temporaryDirectory(t);
  const lock = path.join(directory, ".renamer.lock");
  mkdirSync(lock);
  writeFileSync(path.join(lock, "owner.json"), JSON.stringify({ pid: 2147483647, token: "stale" }));
  put(directory, "a.jpg", "a");

  runRenames(directory, "*.jpg", "photo-#.jpg");

  assert.equal(readFileSync(path.join(directory, "photo-001.jpg"), "utf8"), "a");
  assert.equal(readdirSync(directory).some((name) => name.startsWith(".renamer.lock")), false);
});

test("rolls completed steps back after an application failure", (t) => {
  const directory = temporaryDirectory(t);
  put(directory, "a.jpg", "a");
  put(directory, "b.jpg", "b");
  const plan = [
    { from: "a.jpg", to: "one.jpg" },
    { from: "b.jpg", to: "two.jpg" }
  ];
  let calls = 0;
  const failingRename = (from, to) => {
    calls += 1;
    if (calls === 2) throw new Error("application broke");
    renameSync(from, to);
  };

  assert.throws(
    () => applyRenames(directory, plan, failingRename),
    (error) => error instanceof RenameApplyError &&
      error.cause.message === "application broke" &&
      error.rollbackFailures.length === 0
  );
  assert.equal(readFileSync(path.join(directory, "a.jpg"), "utf8"), "a");
  assert.equal(readFileSync(path.join(directory, "b.jpg"), "utf8"), "b");
});

test("retains the original error and every rollback failure", (t) => {
  const directory = temporaryDirectory(t);
  put(directory, "a.jpg");
  put(directory, "b.jpg");
  const plan = [
    { from: "a.jpg", to: "one.jpg" },
    { from: "b.jpg", to: "two.jpg" }
  ];
  let calls = 0;
  const failingRename = (from, to) => {
    calls += 1;
    if (calls === 2) throw new Error("original failure");
    if (calls === 3) throw new Error("rollback failure");
    renameSync(from, to);
  };

  assert.throws(
    () => applyRenames(directory, plan, failingRename),
    (error) => error instanceof RenameApplyError &&
      error.cause.message === "original failure" &&
      error.rollbackFailures.length === 1 &&
      error.rollbackFailures[0].cause.message === "rollback failure"
  );
});
