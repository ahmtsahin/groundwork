# Atomic rename runs

## Request as understood

Fix bulk renaming so an existing target cannot stop the command halfway and leave earlier files renamed.

## Path

Bounded. The existing single-directory flow in `src/rename.js` owns planning and application; no new subsystem, public schema, or persistent state is introduced.

## Questions and answers

1. When an unplanned file occupies a target: **Abort upfront**.
2. When another renamer changes the same directory during a run: **Refuse overlap**.
3. When a filesystem operation fails after work begins: **Roll back run**.
4. When preflight rejects a plan: **Print after success**, so rejected work produces no stdout mappings.
5. When several sources have one target: **Abort upfront**.
6. When a repeat run contains source-to-same-name steps: **No-op success**.
7. When a dead process left the overlap marker: **Reclaim if dead**.
8. Contract confirmation: **Implement it**.

## Probe ledger

1. Scope exclusions — no undo, persistent journal, recursion, skipping, or overwriting: **repository:** `README.md` “Out of scope”, the single-directory description, and `src/match.js`.
2. Empty input — an empty match produces an empty plan and a successful no-op: **repository:** `planRenames` maps the array returned by `matchFiles` in `src/rename.js`.
3. Duplicate input — several sources targeting one name reject before changes: **user:** “If multiple sources map to the same destination?” → Abort upfront.
4. Concurrent input — this command is in flight and a second scripted or accidental invocation targets the same directory; refuse the second invocation rather than accept newer input: **user:** “If another process adds or changes a relevant file after planning but while renaming?” → Refuse overlap.
5. Partial operation — any filesystem failure after staging begins rolls completed moves back: **user:** “If a filesystem error occurs after renaming has begun?” → Roll back run.
6. Repeated operation — source-to-identical-target steps succeed without changing the file: **user:** “When a repeated command produces source-to-same-name steps?” → No-op success.
7. Failed input — missing sources, occupied external targets, non-local names, and duplicate sources or targets fail validation before staging: **repository:** `validatePlan` and `assertLocalName` in `src/rename.js`.
8. State location — coordination state is a directory-keyed marker in the operating-system temporary directory; move state is held in memory and temporary files stay in the renamed directory: **repository:** `lockPathFor` and `applyRenames` in `src/rename.js`.
9. State lifetime — the marker exists only during apply; a dead local PID's marker is reclaimed: **user:** “If a prior process died and left the overlap marker?” → Reclaim if dead.
10. Migration — no persistent application state or file format changes: **cannot arise:** the change introduces only transient lock and staging files.
11. Shape readers — `src/cli.js` and tests consume `{ from, to }` plan entries: **repository:** imports and assertions in `src/cli.js` and `test/rename.test.js`.
12. Compatibility — keep the plan shape and successful mapping format, but do not print rejected plans: **user:** “When preflight rejects a plan, should stdout still list the proposed renames?” → Print after success.
13. Authority — the local caller who can invoke the CLI may rename files in the supplied directory: **repository:** the positional CLI contract in `README.md` and `src/cli.js`.
14. Validation — sources must exist, targets must be unique and local, and external targets must be absent: **repository:** `validatePlan` in `src/rename.js` and the single-directory contract in `README.md`.
15. Recording — no rename journal is written: **repository:** `README.md` “Out of scope”.
16. Failure visibility — failures use stderr/nonzero process behavior and emit no success mappings on stdout: **repository:** stdout/stderr convention in `AGENTS.md` plus apply-before-print ordering in `src/cli.js`.
17. Failure leftovers — validation leaves names untouched; runtime failures restore original names and clean the lock, while incomplete rollback is surfaced as an aggregate error: **user:** “If a filesystem error occurs after renaming has begun?” → Roll back run.
18. Seam placement — extend the existing plan/apply interface rather than open a new public interface: **repository:** `src/rename.js`, `src/cli.js`, and `test/rename.test.js`.

## Resolved contract

Rename runs are all-or-nothing within one directory. Before moving anything, reject missing or duplicate sources, duplicate targets, path-escaping names, and targets occupied by files outside the moving plan. Serialize applications per resolved directory, reclaim markers owned by dead local processes, stage planned moves so target chains are safe, and roll back original names after runtime failure. Identical source and target names are successful no-ops. The CLI prints mappings only after the apply succeeds. Undo, a persistent journal, recursion, conflict skipping, and overwriting are excluded.

The acceptance check was `node --test --experimental-test-isolation=none test/*.test.js`: all six tests passed, covering planning, collision atomicity, target chains, duplicate rejection, repeat no-ops, and rollback after a forced post-staging failure. The repository's plain `npm test` command could not create Node's test worker in the managed environment (`spawn EPERM`); running the same suite without worker isolation passed.

import { renameSync } from "node:fs";
import path from "node:path";

import { matchFiles } from "./match.js";

export function planRenames(directory, pattern, replacement) {
  return matchFiles(directory, pattern).map((name, index) => ({
    from: name,
    to: replacement.replace("#", String(index + 1).padStart(3, "0"))
  }));
}

export function applyRenames(directory, plan) {
  for (const step of plan) {
    // Throws EEXIST on collision and leaves earlier renames applied.
    renameSync(path.join(directory, step.from), path.join(directory, step.to));
  }
}

--- after ---
import {
  closeSync,
  existsSync,
  openSync,
  readFileSync,
  renameSync,
  unlinkSync,
  writeFileSync
} from "node:fs";
import { createHash, randomUUID } from "node:crypto";
import os from "node:os";
import path from "node:path";

import { matchFiles } from "./match.js";

export function planRenames(directory, pattern, replacement) {
  return matchFiles(directory, pattern).map((name, index) => ({
    from: name,
    to: replacement.replace("#", String(index + 1).padStart(3, "0"))
  }));
}

function assertLocalName(name, field) {
  if (typeof name !== "string" || name.length === 0 || name === "." ||
      name === ".." || path.basename(name) !== name) {
    throw new Error(`${field} must be a file name in the renamed directory: ${name}`);
  }
}

function validatePlan(directory, plan) {
  const sources = new Set();
  const targets = new Set();

  for (const { from, to } of plan) {
    assertLocalName(from, "source");
    assertLocalName(to, "target");
    if (sources.has(from)) throw new Error(`duplicate source in rename plan: ${from}`);
    if (targets.has(to)) throw new Error(`duplicate target in rename plan: ${to}`);
    sources.add(from);
    targets.add(to);
  }

  for (const { from } of plan) {
    if (!existsSync(path.join(directory, from))) {
      throw new Error(`rename source does not exist: ${from}`);
    }
  }

  for (const { from, to } of plan) {
    if (from === to || sources.has(to)) continue;
    if (existsSync(path.join(directory, to))) {
      throw new Error(`rename target already exists: ${to}`);
    }
  }
}

function lockPathFor(directory) {
  const key = createHash("sha256").update(path.resolve(directory)).digest("hex");
  return path.join(os.tmpdir(), `renamer-${key}.lock`);
}

function ownerIsRunning(pid) {
  if (!Number.isSafeInteger(pid) || pid <= 0) return true;
  try {
    process.kill(pid, 0);
    return true;
  } catch (error) {
    return error.code !== "ESRCH";
  }
}

function acquireLock(directory) {
  const lockPath = lockPathFor(directory);
  for (let attempt = 0; attempt < 2; attempt += 1) {
    try {
      const descriptor = openSync(lockPath, "wx");
      writeFileSync(descriptor, JSON.stringify({ pid: process.pid }));
      closeSync(descriptor);
      return lockPath;
    } catch (error) {
      if (error.code !== "EEXIST") throw error;
      let owner;
      try {
        owner = JSON.parse(readFileSync(lockPath, "utf8"));
      } catch {
        throw new Error(`renamer is locked; remove stale marker ${lockPath}`);
      }
      if (ownerIsRunning(owner.pid)) {
        throw new Error(`another renamer is already running for ${path.resolve(directory)}`);
      }
      unlinkSync(lockPath);
    }
  }
  throw new Error(`could not acquire rename lock for ${path.resolve(directory)}`);
}

function rollback(directory, moves, originalError) {
  const rollbackErrors = [];
  for (const move of moves) {
    try {
      const current = path.join(directory, move.current);
      if (!existsSync(current)) continue;
      let temporary;
      do temporary = `.renamer-rollback-${randomUUID()}.tmp`;
      while (existsSync(path.join(directory, temporary)));
      renameSync(current, path.join(directory, temporary));
      move.current = temporary;
    } catch (error) {
      rollbackErrors.push(error);
    }
  }
  for (const move of [...moves].reverse()) {
    try {
      const current = path.join(directory, move.current);
      if (existsSync(current)) renameSync(current, path.join(directory, move.from));
    } catch (error) {
      rollbackErrors.push(error);
    }
  }
  if (rollbackErrors.length > 0) {
    throw new AggregateError(
      [originalError, ...rollbackErrors],
      `rename failed and rollback was incomplete: ${originalError.message}`
    );
  }
  throw originalError;
}

export function applyRenames(directory, plan) {
  const lockPath = acquireLock(directory);
  const moves = [];
  try {
    validatePlan(directory, plan);
    try {
      for (const step of plan.filter(({ from, to }) => from !== to)) {
        let temporary;
        do temporary = `.renamer-${randomUUID()}.tmp`;
        while (existsSync(path.join(directory, temporary)));
        renameSync(path.join(directory, step.from), path.join(directory, temporary));
        moves.push({ ...step, current: temporary });
      }
      for (const move of moves) {
        renameSync(path.join(directory, move.current), path.join(directory, move.to));
        move.current = move.to;
      }
    } catch (error) {
      rollback(directory, moves, error);
    }
  } finally {
    unlinkSync(lockPath);
  }
}

--- after ---
import assert from "node:assert/strict";
import {
  mkdtempSync,
  readFileSync,
  readdirSync,
  rmSync,
  writeFileSync
} from "node:fs";
import os from "node:os";
import path from "node:path";
import test from "node:test";

import { applyRenames, planRenames } from "../src/rename.js";

function temporaryDirectory(t) {
  const directory = mkdtempSync(path.join(os.tmpdir(), "renamer-test-"));
  t.after(() => rmSync(directory, { recursive: true, force: true }));
  return directory;
}

test("the plan numbers matches from one and pads to three digits", () => {
  const plan = planRenames("fixtures", "*.jpg", "photo-#.jpg");
  assert.deepEqual(plan.slice(0, 2), [
    { from: "a.jpg", to: "photo-001.jpg" },
    { from: "b.jpg", to: "photo-002.jpg" }
  ]);
});

test("a collision rejects the entire plan before any rename", (t) => {
  const directory = temporaryDirectory(t);
  writeFileSync(path.join(directory, "a.jpg"), "a");
  writeFileSync(path.join(directory, "b.jpg"), "b");
  writeFileSync(path.join(directory, "taken.jpg"), "taken");

  assert.throws(() => applyRenames(directory, [
    { from: "a.jpg", to: "free.jpg" },
    { from: "b.jpg", to: "taken.jpg" }
  ]), /target already exists/);

  assert.equal(readFileSync(path.join(directory, "a.jpg"), "utf8"), "a");
  assert.equal(readFileSync(path.join(directory, "b.jpg"), "utf8"), "b");
  assert.equal(readFileSync(path.join(directory, "taken.jpg"), "utf8"), "taken");
  assert.equal(readdirSync(directory).some((name) => name.startsWith(".renamer-")), false);
});

test("planned target chains are staged without collisions", (t) => {
  const directory = temporaryDirectory(t);
  writeFileSync(path.join(directory, "a.jpg"), "a");
  writeFileSync(path.join(directory, "b.jpg"), "b");

  applyRenames(directory, [
    { from: "a.jpg", to: "b.jpg" },
    { from: "b.jpg", to: "c.jpg" }
  ]);

  assert.equal(readFileSync(path.join(directory, "b.jpg"), "utf8"), "a");
  assert.equal(readFileSync(path.join(directory, "c.jpg"), "utf8"), "b");
});

test("duplicate targets reject the entire plan", (t) => {
  const directory = temporaryDirectory(t);
  writeFileSync(path.join(directory, "a.jpg"), "a");
  writeFileSync(path.join(directory, "b.jpg"), "b");

  assert.throws(() => applyRenames(directory, [
    { from: "a.jpg", to: "same.jpg" },
    { from: "b.jpg", to: "same.jpg" }
  ]), /duplicate target/);
  assert.deepEqual(readdirSync(directory).sort(), ["a.jpg", "b.jpg"]);
});

test("a repeated self-rename is a successful no-op", (t) => {
  const directory = temporaryDirectory(t);
  writeFileSync(path.join(directory, "same.jpg"), "unchanged");

  applyRenames(directory, [{ from: "same.jpg", to: "same.jpg" }]);

  assert.equal(readFileSync(path.join(directory, "same.jpg"), "utf8"), "unchanged");
});

test("a failure after staging rolls every source back", (t) => {
  const directory = temporaryDirectory(t);
  writeFileSync(path.join(directory, "a.jpg"), "a");
  writeFileSync(path.join(directory, "b.jpg"), "b");
  const invalidTarget = `${"x".repeat(300)}.jpg`;

  assert.throws(() => applyRenames(directory, [
    { from: "a.jpg", to: "renamed.jpg" },
    { from: "b.jpg", to: invalidTarget }
  ]));

  assert.deepEqual(readdirSync(directory).sort(), ["a.jpg", "b.jpg"]);
  assert.equal(readFileSync(path.join(directory, "a.jpg"), "utf8"), "a");
  assert.equal(readFileSync(path.join(directory, "b.jpg"), "utf8"), "b");
});
